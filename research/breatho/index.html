Breatho: Real-Time Respiratory Guidance System for Amateur Runners

Y. Tao, Tingxiao Wu, and Shaoyu Cai

StatusAccepted

Project hero imageRecommended file: /assets/images/breatho/hero.webp

Overview

Breatho explores respiratory guidance as an embodied interaction problem. The system senses and communicates breathing information during running, providing timely feedback without demanding sustained visual attention.

Project contributions

  1. 01A wearable concept for respiratory guidance during physical activity.
  2. 02Real-time feedback designed for low-attention use while running.
  3. 03An integrated prototype connecting sensing, guidance, and embodied experience.

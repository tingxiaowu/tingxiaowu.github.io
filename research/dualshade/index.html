DualShade: A Fail-Safe Dual-Layer Adaptive Eyewear for Real-Time Glare and Luminance Control

Tingxiao Wu, Y. Tao, and Shaoyu Cai

StatusResearch prototype
ContextNUS Engineering Design & Innovation
AreaWearable interfaces
Project hero imageRecommended file: /assets/images/dualshade/hero.webp

Overview

DualShade explores a two-layer strategy for driving-related glare management. A global adaptive tint responds to ambient luminance, while a segmented transparent display selectively attenuates localised glare while preserving critical road information.

Project contributions

  1. 01A dual-layer architecture separating global luminance adaptation from local glare control.
  2. 02A readability-first interaction strategy for preserving safety-critical visual cues.
  3. 03Functional eyewear prototypes supported by technical and user evaluation.
